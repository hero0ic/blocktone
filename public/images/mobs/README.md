# Mob Render Images

Drop PNG renders of Minecraft mobs here. Each file should match the `id` in `challenges.json`:

```
creeper.png
enderman.png
zombie.png
iron_golem.png
wither_skeleton.png
```

Update the `render` field in `challenges.json` from `.svg` to `.png` once your renders are ready.

Recommended: transparent-background PNG, roughly 256×256 or larger, front-facing mob render (not raw skin textures).
